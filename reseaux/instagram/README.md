# Skills Instagram

Six commandes, inspirées de la vidéo « Instagram Agent Skills » (TikTok @henriexploria,
2026-11-27), refaites pour Les Naufragés. Compte : @twich_lordmattstark.

| Commande | Ce qu'elle fait | Fichier écrit |
|---|---|---|
| `/ig-profil` | note le profil sur 100 + bio, nom, lien prêts à coller | `AAAA-MM-JJ/1-profil.md` |
| `/ig-viral` | trouve les Reels qui explosent, explique pourquoi, écrit notre script | `AAAA-MM-JJ/2-viral.md` |
| `/ig-plan` | planning de 7 jours avec les vidéos déjà prêtes | `AAAA-MM-JJ/3-planning.md` |
| `/ig-post` | un post prêt à copier (accroche parmi les 21, légende, hashtags) | `posts/…md` |
| `/ig-reponses` | réponses aux commentaires, à valider | `AAAA-MM-JJ/4-reponses.md` |
| `/ig-commenter` | 10 commentaires utiles à poster à la main chez les autres | `AAAA-MM-JJ/5-commentaires.md` |

Les 21 accroches : [accroches.md](accroches.md).

## Différences avec la vidéo
- **Rien n'est publié ni envoyé sans le « oui » de lord** (règle de `../niche.md`).
- **Pas de commentaires automatiques** chez les autres : Instagram bannit les comptes qui
  le font. `/ig-commenter` prépare, lord colle à la main.
- Pas de connexion à ton mot de passe Instagram : les données publiques viennent de vidIQ.

## Lancer
Dans un fil du projet Claude, ou sur le PC (`claude` dans le dossier du dépôt) :
tape la commande, par exemple `/ig-plan`. Les dossiers du jour vont dans
`/mnt/project-files/reseaux/instagram/` (fils du projet) ou `reseaux/instagram/sorties/` (PC).
