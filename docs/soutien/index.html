Aucun avantage en jeu, promis.

Les grades Soutien sont purement cosmétiques, comme l'exigent les règles commerciales de Mojang. Les montures des grades vont exactement aussi vite que le cheval de ferme gratuit. Les machines, les armes, les homes, les métiers, l'argent et les coffres se gagnent uniquement en jouant.

Objectif du mois : 50 €

Quand l'objectif est atteint, tout le serveur gagne un week-end Double XP de métiers. Même ceux qui n'ont rien acheté.

Comment ça marche

Trois étapes.

1. Clique sur le grade de ton choix. Tu arrives sur notre boutique sécurisée Tebex (carte, PayPal, Bancontact…).

2. Entre ton pseudo Minecraft exact. Sur Bedrock, avec le point devant (ex. .Pseudo).

3. Le grade arrive tout seul en jeu en quelques minutes (connecte-toi au serveur). Un souci ? Écris-nous sur le Discord avec ton reçu.

Moins de 18 ans ? Demande à un parent : c'est lui qui paie. Les conditions de vente sont ici.
