# Équipe réseaux

Six agents Claude font tourner la chaîne de Shorts ; lord dit seulement oui ou non.

| N° | Agent | Rôle |
|---|---|---|
| 1 | chercheur | repère les sujets qui montent dans la niche |
| 2 | espion | analyse les vidéos des concurrents qui explosent |
| 3 | scenariste | écrit 3 scripts avec accroche + voix off + sources |
| 4 | realisateur | « tourne » en 3D codée (pas de visage IA) |
| 5 | monteur | sous-titres, musique, formats 9:16 / 16:9 |
| 6 | publieur | feu vert de lord, puis mise en ligne à la bonne heure |

## Lancer
- Dans un fil du projet Claude : « lance l'équipe réseaux ».
- Sur le PC : ouvrir un terminal dans le dossier du dépôt, `claude`, puis
  « lance l'équipe réseaux » (le skill `.claude/skills/equipe-reseaux` s'active).

Ligne éditoriale, règles et concurrents suivis : [niche.md](niche.md).
