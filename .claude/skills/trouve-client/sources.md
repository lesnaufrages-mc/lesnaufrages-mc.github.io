# Sources des 6 chercheurs

1. **Reddit CK3** : r/CKMods, r/CrusaderKings (mots : "is there a mod", "mod request",
   "looking for a mod", "someone make a mod", "commission").
2. **Forum Paradox** : forum.paradoxplaza.com, section CK3 « User Modifications » et
   « Mod requests » ; fils « Is there a mod that… ».
3. **Steam** : discussions de la communauté CK3 et du Workshop (« mod request »,
   « outdated », « update this mod please ») + commentaires sous les mods CK3
   abandonnés (non mis à jour depuis la 1.13 ou avant) : proposer la mise à jour.
4. **Nexus Mods** : CK3 (forums « Mod requests », posts et commentaires des 7 mods
   des Naufragés : 432, 433, 469 à 473) : les gens qui ont déjà « mangé chez nous ».
5. **Minecraft francophone** : minecraft-france, serveurs-minecraft / forums de
   recrutement, Reddit r/admincraft, r/MinecraftPlugins ("plugin request", "looking for a
   developer", "cherche développeur plugin").
6. **Places de commission** : BuiltByBit « Requests / Hiring », Fiverr Forum et
   X/Twitter public (« need a CK3 modder », « hiring minecraft plugin dev »).
