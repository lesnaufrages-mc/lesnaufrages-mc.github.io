# /ig-plan : planning de la semaine

1. Liste les vidéos prêtes : dossiers `videos/*/` du projet (mp4 9:16 + description).
   Ajoute ce qui sort cette semaine sur le site, le serveur Minecraft ou les mods CK3.
2. Rythme : **4 Reels, 1 Carrousel, Stories tous les jours** (les Stories gardent le lien
   cliquable avec le sticker « Lien »). Mélange : 3 histoire 3D, 1 jeu / serveur.
3. Heures (public belge et français, 15-30 ans) : semaine 12 h 30 ou 18 h 30,
   week-end 11 h ou 20 h. Après 4 semaines, remplace-les par les meilleures heures
   réelles des statistiques Instagram.
4. Écris `reseaux/instagram/AAAA-MM-JJ/3-planning.md` : un tableau (jour, heure, type,
   fichier, accroche) puis, pour chaque jour, la légende complète faite avec `/ig-post`.
5. Si une vidéo a déjà été postée sur Instagram, ne la remets pas : vérifie avec
   `vidiq_ig_profile_reels`.

Rien n'est publié sans le « oui » de lord. Instagram permet de programmer un post
depuis l'appli (Paramètres avancés > Programmer) : lord peut tout programmer d'un coup.
