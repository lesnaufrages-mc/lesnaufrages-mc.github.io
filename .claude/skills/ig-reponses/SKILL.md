# /ig-reponses : répondre aux commentaires

1. Récupère les commentaires : `vidiq_instagram_comment_list` si le compte Instagram est
   connecté à vidIQ (`vidiq_social_account_list`), sinon lord colle les commentaires.
2. Pour chaque commentaire, écris une réponse :
   - courte (1 ou 2 phrases), tutoiement, ton de lord, un emoji maximum ;
   - **relance avec une question** quand c'est possible (plus de commentaires = plus de portée) ;
   - question sur un jeu / le serveur : réponse + « lien en bio » ;
   - critique : on remercie, on corrige si c'est vrai, on ne se dispute jamais ;
   - insulte, spam, arnaque : « à masquer », pas de réponse.
3. Écris `reseaux/instagram/AAAA-MM-JJ/4-reponses.md` : commentaire, réponse proposée.
4. N'envoie **rien** sans le « oui » de lord pour chaque réponse.
